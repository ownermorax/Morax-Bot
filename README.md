# Morax Telegram Bot

Персональный Telegram-бот для мониторинга сообщений, поиска по базе данных, браузерной автоматизации и перелива цветов кнопок.

## Возможности

### 📨 Мониторинг сообщений
- Отслеживание всех входящих/исходящих сообщений через Business Connections
- Автоматическое обнаружение удалённых сообщений — уведомление с содержимым и медиа
- Автоматическое обнаружение изменённых сообщений — показ старой и новой версии
- Сохранение медиафайлов (фото, видео, голосовые, стикеры, документы, GIF)
- Автоматический экспорт истории чата при удалении бота из группы

### 🔍 Поиск по базе данных
- Inline-поиск по текстовой базе (`base.txt`) с записями людей
- Поиск по имени, телефону, Telegram ID, username, email, паспорту, СНИЛС
- Результаты содержат: ФИО, дату рождения, телефоны, адреса, паспортные данные, родственников
- Быстрый копировать Telegram ID одной кнопкой

### 🌐 Браузерная автоматизация
- Циклическая отправка запросов на web.telegram.org через Selenium
- Запуск/остановка для каждого номера отдельно
- Команды: `/add_web`, `/start_web_*`, `/stop_web_*`, `/del_web_*`

### 🎨 Перелив цветов кнопок
- Автоматическая смена цвета inline-кнопок в канале каждые 0.4 секунды
- Работает через **отдельный процесс** `1bot.py` (изолированный Telebot через Tor)
- Цвета: 🔴 Красный, 🔵 Синий, 🟢 Зелёный
- Использует **второго бота** (отдельный токен) через Bot API HTTP + SOCKS5

## Настройка конфигурации

Перед запуском нужно заполнить `config.py` своими данными. В репозитории есть `config-example.py` — скопируй его и подставь свои значения:

```bash
cp config-example.py config.py
```

### Поля для заполнения

| Поле | Описание | Где взять |
|------|----------|-----------|
| `API_ID` | ID приложения Telegram | [my.telegram.org/apps](https://my.telegram.org/apps) |
| `API_HASH` | Хеш приложения Telegram | [my.telegram.org/apps](https://my.telegram.org/apps) |
| `BOT_TOKEN` | Токен основного бота | [@BotFather](https://t.me/BotFather) |
| `MY_USER_ID` | Твой Telegram ID | [@userinfobot](https://t.me/userinfobot) |
| `BOT_TOKEN_2` | Токен второго бота (для перелива кнопок) | [@BotFather](https://t.me/BotFather) |
| `CHANNEL_ID` | ID канала для перелива | ID твоего канала |
| `MESSAGE_ID` | ID сообщения для перелива | Числовой ID поста |
| `BUTTONS_DATA` | Массив кнопок для перелива | Текст, URL |

# Установка ChromeDriver (для Selenium)

## Требования

- Python 3.10+
- Google Chrome + ChromeDriver (для Selenium-автоматизации)
- Tor (SOCKS5 на порту 9050) — обязателен для работы бота

## Архитектура

Бот состоит из двух независимых процессов, запускаемых из `main.py`:

### 1. Основной бот (Kurigram/Pyrogram MTProto)
- `main.py` — точка входа, инициализация клиента
- `handlers/` — обработчики команд, бизнес-сообщений, инлайн-запросов
- Использует MTProto через SOCKS5 + socket-patch (редирект `149.154.*` на рабочий DC)
- **Не может** редактировать reply markup чужих сообщений (ограничение MTProto)

### 2. Перелив кнопок (Telebot Bot API HTTP)
- `1bot.py` — запускается как **отдельный процесс** через `subprocess.Popen`
- Использует `telebot` (Telegram Bot API HTTP) с явной настройкой SOCKS5 прокси
- `button_cycles.py` — заглушка, все функции пустые
- `handlers/buttons.py` — меню управления в основном боте (вызывает заглушки)

### Почему два процесса?
- Kurigram/Pyrogram (MTProto) не умеет редактировать inline keyboard чужих сообщений
- `requests` падает с SSL-ошибками (не проходит через сокет-патч)
- `telebot` + `socks5h://127.0.0.1:9050` работает и не блокирует asyncio-цикл

## Структура проекта

```
bot/
├── main.py                 # Точка входа (запускает основной бот + 1bot.py)
├── 1bot.py                 # Изолированный Telebot для перелива кнопок
├── config.py               # Конфигурация и API-ключи
├── config-example.py       # Пример конфигурации
├── storage.py              # Хранилища данных (MessageStorage)
├── database.py             # Парсер базы данных (PersonDatabase)
├── utils.py                # Вспомогательные функции
├── web_tasks.py            # Управление браузерными задачами
├── web_handler.py          # Selenium-автоматизация
├── background.py           # Фоновые задачи (автосохранение, проверка чатов)
├── button_cycles.py        # Заглушка (реальный перелив в 1bot.py)
├── handlers/               # Обработчики команд и сообщений
│   ├── __init__.py         # Регистрация всех хендлеров
│   ├── business.py         # Бизнес-сообщения (удаление, изменение)
│   ├── inline.py           # Инлайн-запросы и колбэки
│   ├── commands.py         # Команды (/stats, /help, и т.д.)
│   └── buttons.py          # Управление переливом кнопок
├── example.py              # Референс-пример перелива (не используется)
├── base.txt                # База данных людей
├── web_tasks.json          # Номера для Selenium-задач
├── bot_data/               # JSON-файлы состояния
├── deleted_media/          # Сохранённые медиафайлы
├── deleted_chats/          # Экспортированные чаты
└── server-work/            # Экспериментальная монолитная версия
```

## Важно

- Используется **SOCKS5 прокси (Tor)** — обязательно должен быть запущен на порту 9050
- Два бота = два токена: `BOT_TOKEN` (основной, Kurigram) и `BOT_TOKEN_2` (перелив, Telebot)
- Оба бота должны быть администраторами в целевом канале
- Все API-ключи и токены в `config.py`
- Весь интерфейс на **русском языке**
- Доступ к боту имеет только владелец (`MY_USER_ID`)
- Файл `base.txt` содержит персональные данные — обращаться с осторожностью
